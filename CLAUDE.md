# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Roadmap

The roadmap index is at `docs/ROADMAP.md`. Milestones and issues live in this repository.

**Read the index before planning work here.** It holds the direction, the ordering argument and the known unknowns. It does not hold status — GitHub does.

Milestones are ideas, not work. A milestone with no `feature` issues has not been shaped yet, and nothing may be built from it. Counting open issues is not the test — a milestone can carry research spikes alongside its refinement issue and still be unshaped.

**The gate is a label, so it can be tested rather than judged.** An issue may be built from when it carries `ready`. Labels: `refinement` (shape a milestone), `research` (answer a question, carries an appetite), `feature` (delivery work), `ready` (refined enough to hand off — the only label that authorises building).

Update the index when the direction changes, when a research issue closes, or when the issue graph comes to imply an order the index argues against. In that last case the graph wins.
