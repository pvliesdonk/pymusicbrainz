# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Roadmap

The roadmap index is at `docs/ROADMAP.md`. Milestones and issues live in this repository.

**Read the index before planning work here.** It holds the direction, the ordering argument and the known unknowns. It does not hold status — GitHub does.

Milestones are ideas, not work. A milestone whose only open issue is its refinement issue has not been shaped yet, and nothing may be built from it. Work starts from a refined feature issue.

Update the index when the direction changes, when a research issue closes, or when the issue graph comes to imply an order the index argues against. In that last case the graph wins.
